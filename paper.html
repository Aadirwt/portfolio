Content Prioritization Using SEO Metrics and Decision Tree Classification

Author: Aaditya Singh Rawat

Abstract

This project investigates whether SEO performance metrics can be used to prioritize content optimization opportunities. A Decision Tree Classifier was applied to search volume, CTR, average position, engagement rate, and impression data from an anonymized FlyRank internship dataset. Grouped validation using GroupKFold was used to reduce leakage risk between clients. The model was compared with a rule-based baseline and produced identical accuracy on the grouped split, indicating that the current target definition is strongly aligned with the baseline logic.

Introduction / Problem Statement

Websites generate large volumes of SEO data, making it difficult to decide which pages should be optimized first. Manual review and simple threshold rules do not scale well across thousands of pages. The goal of this project is to build a lightweight and interpretable workflow that identifies pages requiring higher optimization priority using common SEO performance metrics.

Data

  • Dataset: content_refresh_anonymized.csv
  • Rows: ~30,000
  • Columns: 44

Features used:

  • search_volume
  • ctr
  • avg_position
  • engagement_rate
  • impressions_90d

A binary target called priority was created using the Week 4 baseline rule: search volume above the median, CTR below the median, and average position greater than 10.

Methodology

A Decision Tree Classifier (max_depth=4) was selected because it is easy to interpret and suitable for tabular SEO data. The Week 4 rule-based baseline was retained for comparison.

Validation design:

  • Method: GroupKFold(n_splits=5)
  • Grouping column: client_id
  • Training rows: 22,992
  • Testing rows: 7,008

The identical accuracy suggests that the current target variable is strongly determined by the same threshold conditions used in the baseline rule. Therefore, the model should be interpreted as reproducing the baseline behavior rather than demonstrating substantially better predictive performance.

Limitations & Honest Framing

  • The target variable was derived from manually defined thresholds.
  • Accuracy alone is not sufficient to measure SEO business impact.
  • The dataset is anonymized internship data and may not represent all production SEO scenarios.
  • The current label definition is closely aligned with the baseline logic.
  • The workflow is intended for decision support, not autonomous SEO optimization.
